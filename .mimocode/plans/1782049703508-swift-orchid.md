# Plan: Responsive/Adaptive Design for VK-Marusya

## Breakpoint System

| Breakpoint | Target |
|------------|--------|
| `>= 1280px` | Desktop (current, no changes) |
| `1024px – 1279px` | Small desktop / large tablet |
| `768px – 1023px` | Tablet |
| `< 768px` | Mobile |

---

## Phase 1: Search + Header (with hamburger menu)

**`src/components/Search/Search.css`** — replace `width: 655px` with `width: 100%; max-width: 655px`. Add `@media (max-width: 767px)` for full-width input and results.

**`src/App.css`** — reduce padding at `<=1023px` (20px) and `<=767px` (16px). Scale down logo and font sizes. At `<=767px` hide `.header__links` and `.header__btn` by default, show them in an open state via `.header__navbar--open`.

**`src/App.tsx`** — add hamburger toggle state + button:
- Add `useState(false)` for menu open state
- Add hamburger `<button>` (visible only on `<=767px` via CSS)
- Toggle class `header__navbar--open` on the nav element
- Close menu on nav link click

## Phase 2: Banner Components

**`src/components/Hero/Banner/Banner.css`** and **`src/components/Film/FilmBanner/FilmBanner.css`** — both identical layout:
- `<=1023px`: reduce padding/gap to 24px, shrink image container to 300px, scale title to 36px
- `<=767px`: `flex-direction: column`, full-width image with `aspect-ratio: 16/10`, title 28px, wrap action buttons

## Phase 3: Grids (all 5-col → 4 → 3 → 2)

Three files with `repeat(5, 1fr)`:
- **`src/components/Hero/TopMovies/TopMovies.css`**
- **`src/pages/GenreMoviesPage/GenreMoviesPage.css`**
- **`src/components/Profile/ProfileFavorites/ProfileFavorites.css`**

One file with `repeat(4, 1fr)`:
- **`src/pages/GenresPage/GenresPage.css`** → 4 → 3 → 2

All: reduce `gap` from 40px progressively, scale number badges and font sizes.

## Phase 4: Moderate (FilmInfo, Profile, Modals)

- **`src/components/Film/FilmInfo/FilmInfo.css`** — reduce title, label width, padding
- **`src/pages/ProfilePage/ProfilePage.css`** — scale title/nav links, wrap nav
- **`src/components/Modals/AuthModal/AuthModal.css`** — reposition close button, reduce padding
- **`src/components/Modals/TrailerModal/TrailerModal.css`** — use `aspect-ratio: 16/9` instead of fixed height, reposition close button

## Phase 5: Low priority

- **`src/components/Loaders/LoaderMovie.css`** + **`LoaderGenre.css`** — reduce font-size
- **`src/components/GenresListItem/GenresListItem.css`** — reduce image height
- **`src/components/Profile/ProfileSettings/ProfileSettings.css`** — reduce gap/padding
- **`src/pages/HomePage/HomePage.css`** — reduce margins
