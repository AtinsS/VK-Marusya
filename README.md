# Маруся

Веб-приложение для просмотра информации о фильмах. Создано в учебных целях.

Деплой на Vercel: https://marusya-films.vercel.app/

## Технологии

- **React 19** + **TypeScript 6**
- **Vite 8** — сборка и dev-сервер
- **Redux Toolkit** — управление состоянием
- **React Router 7** — маршрутизация
- **React Hook Form** + **Zod** — формы и валидация
- **Axios** — HTTP-запросы
- **React YouTube** — воспроизведение трейлеров
- **Vitest** — Покрытие логики тестами для корректной работы сайта
 
## Запуск

```bash
# Установка зависимостей
npm install

# Dev-сервер
npm run dev

# Сборка
npm run build

# Превью сборки
npm run preview

# Линтинг
npm run lint
```

## Структура проекта

```
src/
├── api/            # API-клиент и запросы (axios)
├── assets/         # SVG-иконки и логотипы
├── components/     # Переиспользуемые компоненты
│   ├── Film/       #   Баннер и информация о фильме
│   ├── Hero/       #   Главный баннер и топ фильмов
│   ├── Loaders/    #   Индикаторы загрузки
│   ├── Modals/     #   Модальные окна (авторизация, трейлер)
│   ├── Profile/    #   Избранное и настройки профиля
│   └── Search/     #   Поиск с debounce
├── entities/       # Типы и схемы (Zod)
├── hooks/          # Кастомные хуки (useAuth, useFavorite, useDebounce)
├── pages/          # Страницы приложения
│   ├── HomePage/       # Главная — баннер и топ фильмов
│   ├── GenresPage/     # Список жанров
│   ├── GenreMoviesPage/# Фильмы по жанру
│   ├── FilmPage/       # Детальная страница фильма
│   └── ProfilePage/    # Профиль (избранное, настройки)
├── store/          # Redux store и слайсы
├── utils/          # Утилиты
└── App.tsx         # Корневой компонент с роутингом
```

## Маршруты

| Путь | Описание | Доступ |
|------|----------|--------|
| `/` | Главная страница | Публичный |
| `/genres` | Список жанров | Публичный |
| `/genres/:genre` | Фильмы по жанру | Публичный |
| `/movie/:id` | Страница фильма | Публичный |
| `/profile/favorites` | Избранные фильмы | Авторизованные |
| `/profile/settings` | Настройки профиля | Авторизованные |
